Ghost Git Writer GitHub

Let the ghost write your commits.

ggw is a small CLI that reads your git diff and asks an LLM (Gemini or OpenAI) to write the commit message — then commits it for you, after a single y/n. Built with TypeScript and Bun, shipped as standalone binaries. 

❯ ggw
        ⠏ Calling gemini-3.5-flash ...

        feat: add stdin diff input and diff range options

        git commit as this message? (y/n) y
        ok.

Tools

  • ggwgenerate a Conventional Commits message from the diff, confirm, and commit
  • sumdiffsummarize what changed in a diff — additions, removals, and why they matter
  • which-semsuggest which SemVer part (major / minor / patch) the diff should bump

Install

Build single-file binaries with Bun:

❯ git clone https://github.com/Uliboooo/ghost_git_writer
        ❯ cd ghost_git_writer
        ❯ bun install
        ❯ bun run build # → dist/ggw, dist/sumdiff, dist/which-sem

Set GEMINI_API_KEY (or OPENAI_API_KEY) in your environment before running.

Options

All three tools share the same flags:

Flag Description
-m, --model LLM as provider/model, e.g. gemini/gemini-3.5-flash or openai/…
-l, --lang output language (default: English)
-p, --path git project root (default: current directory)
-D, --diff diff range — commits or branches
-I, --stdin read the diff from stdin instead of git
-o, --oneline which-sem only: print just the SemVer part name 
❯ ggw -l Japanese -D main develop
        ❯ git diff HEAD~3 | sumdiff -I
        ❯ which-sem -o # → Minor

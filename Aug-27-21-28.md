# ghost_git_writer

[![made-with-Rust](https://img.shields.io/badge/Made%20with-Rust-1f425f.svg)](https://www.rust-lang.org/)
[![GitHub Repository](https://img.shields.io/github/stars/Uliboooo/ghost_git_writer?style=social)](https://github.com/Uliboooo/ghost_git_writer)

`ghost_git_writer` (ggw) is a command-line tool that leverages LLM (Large Language Model) services to automatically generate Git commit messages, README files, and diff summaries from your codebase.

**⚠️ beta ⚠️** and this doc is unstable to updating now...

## Key Features

- **Commit Message Generation:**  Automatically create descriptive commit messages from Git diffs.
- **README Generation:** Generate README.md files from your codebase, helping to document your projects.
- **Diff Summarization:** Summarize changes from Git diffs to quickly understand modifications.
- **Multi-LLM Support:** Utilizes `llm-api-rs` and `ollama-rs` to interface with various LLM providers like Gemini and Ollama.
- **Customizable Prompts:** Allows you to specify custom prompts to tailor the output of the LLM.
- **Configuration:** Supports configuration files to manage LLM settings and custom prompts.
- **Multi Language Support:** Output language.

## Technologies Used

- **Rust:** The core language for performance and safety.
- **clap:** For command-line argument parsing.
- **git2:**  For interacting with Git repositories.
- **ollama-rs:** For interfacing with local Ollama models.
- **llm-api-rs:** For interacting with cloud LLM services.
- **serde:** For serialization and deserialization.
- **derive-getters:** For automatically generating getter methods.
- **chrono:** For date and time handling.
- **home:** For resolving the user's home directory.
- **easy_storage:** For easy configration management.
- **indicatif:** For showing progress.
- **tokio:** For asynchronous runtime.

## Installation

```zsh
cargo install ghost_git_writer
```

## How to Run the Project

```zsh
ggw <COMMAND> [Options]
```

### Commands

- `commit`: Generate a Git commit message from Git diff using LLM.
- `readme`: Generate a README from the codebase.
- `sumdiff`: Generate a summary of changes from Git diff.

### Global Options (Mainly)

- `-m, --model <MODEL>`: Model specific tag. There are two patterns to specify a model:
  - `<provider>/<model>` (e.g., `gemini/gemini-2.0-flash`).
- `-p, --path <PATH>`: Specific work path. If it's empty, the current directory path is used.
- `-l, --lang <LANGUAGE>`: Change output language. (default=english). E.g., `-l japanese`
- `-e, --extra <PROMPT>`: Extra prompt. If you need to append order to LLM.
- `--config <PATH>`: Config file path. If you need to locate other than `~/.config/ggw/config.toml` or `~/.ggw.toml`.

### Example Usages

1.  **Generate a commit message:**

    ```zsh
    ggw commit -m gemini/gemini-2.0-flash
    ```

2.  **Generate a README for the current directory:**

    ```zsh
    ggw readme
    ```

3.  **Generate a README from a specific directory:**

    ```zsh
    ggw readme -p /path/to/your/project
    ```

4.  **Summarize a diff and output in Japanese:**

    ```zsh
    ggw sumdiff -l japanese -m gemini/gemini-2.0-flash
    ```

5. **Setting a custom prompt:**

   ```zsh
   ggw commit -e "Please make the commit message very concise." -m gemini/gemini-2.0-flash
   ```

## Configuration

`ghost_git_writer` uses a configuration file to manage settings for LLM providers and custom prompts.

**Configuration File Locations:**

1.  `~/.config/ggw/config.toml`
2.  `~/.ggw.toml`

**Example Configuration File (`~/.config/ggw/config.toml`):**

```toml
[prompt.custom_prompt]
test = "this is test"

[llm]
default_alias = "ge"

[llm.model_alias.ge]
provider = "gemini"
model = "gemini-2.0-flash"
```
